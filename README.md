# Oyster and Dungeness Crab Suitability Analysis by Exclusive Economic Zone in California

### Purpose: 
This repo houses code and visualizations for analyses performed using average annual sea surface temperature, bathymetry, and Exclusive Economic Zone data. 

### Repository Structure: 

### Data Access: 
Bathymetry Data accessed via GEBCO Compilation Group (2022). 

SeaLifeBase website was utilized to find Dungeness Crab data. 

NOAA Sea Surface Temperature accessed via NOAA Coral Reef Watch. 

Exclusive Economic Zone data accessed via Marine Regions for California EEZs.
